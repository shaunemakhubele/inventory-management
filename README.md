# Java Inventory Management System

A beginner portfolio project built with Java to practise object-oriented programming, collections, input validation, file handling, and Git version control.

## Features

- Add and view products
- Search products by name
- Restock existing products
- Remove products with confirmation
- Prevent duplicate product names
- View low-stock products
- Calculate total inventory value
- Display an inventory summary
- Save and load inventory data using a CSV file
- Validate user input

## Technologies

- Java
- ArrayList and object-oriented programming
- Java file I/O
- CSV data storage
- Git and GitHub

## Requirements

- Java Development Kit (JDK) 21 or compatible version
- PowerShell or another terminal

## How to Run

Open a terminal in the project's `src` directory.

Compile the application:

```powershell
javac Product.java Main.java
```

Run it:

```powershell
java Main
```

Follow the numbered menu options to manage the inventory.

## Data Storage

The application saves inventory data in `inventory.csv`. The file is created in the working directory from which the program runs.
